# Merek dan aset resmi

Kode sumber DownloadIn dirilis dengan lisensi **GPL-3.0-or-later**: kamu bebas memakai, mempelajari, mengubah, dan membagikannya.
Yang **tidak** ikut dilisensikan adalah identitas merek. Sesuai GPL-3.0 bagian 7(e), KazamaTech tidak memberikan hak atas merek dagang berikut:

| Aset | Keterangan |
|---|---|
| Nama **DownloadIn**, **KazamaDownloader**, **KazamaTech** | nama aplikasi, website, dan penerbit |
| **Logo KazamaTech** | `public/img/kazamatech.png`, `android/app/src/main/res/drawable-nodpi/kazamatech_logo.webp`, `ios/DownloadIn/Assets.xcassets/KazamaTech.imageset/` |
| **Ikon dan logo DownloadIn** | ikon launcher Android, ikon iOS, `public/img/logo.svg`, ikon PWA |
| Domain dan layanan resmi | `dlin.kazamasite.biz.id` dan server di belakangnya |
| ID paket resmi | `com.kazamatech.dlin` |

## Jika kamu membuat fork atau versi modifikasi

Boleh, dengan syarat:

1. **Ganti nama, logo, ikon, dan ID paket/bundel**. Jangan memakai aset di tabel di atas.
2. **Jangan mengaku sebagai versi resmi** atau seolah-olah dibuat/didukung KazamaTech.
3. **Pertahankan pemberitahuan hak cipta dan lisensi GPL-3.0** (termasuk atribusi karya asal), dan sediakan kode sumber versimu (kewajiban GPL).

## Cara memastikan aplikasi asli

- Unduh hanya dari **dlin.kazamasite.biz.id** atau [GitHub Releases resmi](https://github.com/kazamaofficial-git/KazamaDownloader/releases).
- Di aplikasi Android, halaman **Tentang → Keaslian** menampilkan *Build resmi KazamaTech* bila tanda tangan APK cocok dengan sertifikat resmi, atau peringatan bila tidak.
- Menemukan tiruan atau penyalahgunaan nama? Laporkan lewat [GitHub Issues](https://github.com/kazamaofficial-git/KazamaDownloader/issues).
